# Example records, rules version 0.001

At least three examples of each record type, signed with real keys and listed in the order they were made. Together they form one small chain, so every example is valid under the rules. Some records acknowledge more than one earlier record, which is how branches of the history join. For each record, the payload is shown exactly as signed (canonical JSON, one line), followed by its signature and its record hash.
