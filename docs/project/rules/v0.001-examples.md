# Example records, rules version 0.001

Three examples of each record type, signed with real keys. Together they form one small chain: each record acknowledges the one made before it, so every example is valid under the rules. For each record, the payload is shown exactly as signed (canonical JSON, one line), followed by its signature and its record hash.

Record hashes are shown in full. Where a payload names another record, the examples it names are listed above it by label (I1, M2 and so on); the labels are not part of any record.

## Example keys

Each key's private half is the SHA-256 of `reputablechat example key: <name>`, so anyone can re-derive them. Never use them for anything real.
